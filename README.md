# Google AI Overviews Data Release

## 1. Raw data

[`raw/`](raw/) contains the study inputs, collected results, and final model outputs.

| Folder | Contents |
|---|---|
| [`raw/trends/`](raw/trends/) | Daily Google Trends CSVs, organized by date and category. |
| [`raw/query_results/`](raw/query_results/) | `result.json` for **all query executions**. |
| [`raw/aio_results/`](raw/aio_results/) | The **AIO-returning subset of executions in `query_results/`**, with processed records, cited-page captures, and final model outputs. |

Files stored within AIO observation folders:

| File | Contents |
|---|---|
| `result.json` | AIO text, citations, and search results. |
| `snapshot.html` | Saved search results page. |
| `page_analysis/*.json` | Cited-page text and ad measurements. |
| `claims_grok_4_1.json` | Extracted claims. |
| `verification_prompt_grok.txt` | Verification prompt and source evidence. |
| `verification_result_grok-4-1-fast-reasoning_v2.json` | Claim verification labels and supporting evidence. |

## 2. Code

| Path | Contents |
|---|---|
| [`code/scraper/`](code/scraper/README.md) | Standalone Google AIO/SERP scraper: query input, AIO text and citation extraction, search-result links, and local snapshots. |
| [`code/verifier/`](code/verifier/README.md) | Grok claim extraction, captured-page quality filtering, verification prompt generation, and claim verification. |
| [`replication/`](replication/) | Seven notebooks, ordered by paper section, that reproduce the reported results from `raw/`. |
| [`replication/supporting/`](replication/supporting/) | Credibility inputs and the final paper-defined exclusion and sponsored-ad lists. |
| [`replication/observations.csv`](replication/observations.csv) | Query-level table generated by the AIO activation notebook. |

Install the packages in [`requirements.txt`](requirements.txt) before running the notebooks.
See [`REPRODUCTION_SCOPE.md`](REPRODUCTION_SCOPE.md) for the covered paper results.
